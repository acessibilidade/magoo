# Arquivos para atualizar via FTP — Magoo 1.5.0

Enviar os arquivos abaixo para a raiz do site, preservando os caminhos. Inclua as pastas ocultas e o arquivo .htaccess. A lista cobre os arquivos alterados e novos desta versão; os demais arquivos públicos já existentes devem permanecer no servidor.

Não enviar node_modules, .git, templates, tests, scripts de build ou credenciais.

O ZIP de entrega em /private/tmp/magoo-ftp-1.5.0.zip contém somente estes arquivos. Após o upload, conferir /robots.txt, /sitemap.xml, /.well-known/ard.json, /.well-known/ai-catalog.json, /downloads/magoo-figma.zip, /pt-br e /en. Limpar cache da hospedagem/CDN e executar novamente o PageSpeed.
