# Changelog

## 1.6.0

- Adds File upload, Autocomplete, Dates and ranges, Loading and progress, Cards, and Step indicator, with interaction guides, scenarios, and references.
- Adds Page regions, with guidance on headers, main content, navigation, complementary content, and footers.
- Adds Layout and content order, with guidance on reading and focus sequence, column adaptation, zoom, and keyboard scrolling.
- Revises Gherkin scenarios to cover keyboard navigation and screen readers on desktop and mobile.
- Revises interaction methods to explain user actions and expected outcomes for each input method.

## 1.5.1

- Extends Select, Tables, Menu, and Input search with interaction decisions, quick guides, additional scenarios, and references, preserving IDs and previous guidance.

## 1.5.0

- Adds plain-language quick guides for Modal, Button, and Input text while preserving the full guidance.
- Prepares the Magoo in Figma skill for reviewing and documenting behavior.
- Aligns local snapshot versions and validates differences between package, lockfile, catalog, and components.
- Extends quick guides to all 29 components, with framed panels, 1rem paragraphs, and English translations.
- Adds indexes for the five categories and breadcrumbs linking to parent levels with an unlinked current page.
- Highlights Magoo with Figma on the homepage, with beginner setup guidance and a skill download.
- Fixes validation to work in the npm package without a lockfile and includes the skill in the distribution.

## 1.4.0

- Adds US English as the second native website language, with a translated homepage and documentation for all 29 components; Brazilian Portuguese remains the primary language.
- Centralizes translations and routes in JSON files to simplify adding languages, with Portuguese at /pt-br and English at /en.
- Translates English URLs, preserves the component and section when switching languages, and redirects previous routes.
- Maintains a canonical URL for each language and updates hreflang, the sitemap, Open Graph, and Twitter Cards.
- Adds lists and accessible names to the main menu and language selection, with native buttons, selection state, and a responsive layout.
- Keeps Google Translate for other languages, with the Select other languages label associated with the combo box for screen readers only.
- Displays only the Tudo é Acessibilidade logo in the English footer, removing the institutional phrase and divider from the image.
- Standardizes HTML indentation and keeps opening tags and their attributes on one line, with automatic checks after the build.
- Fixes Apache rules to serve /en and /pt-br without trailing slashes and prevent the English homepage access error.
- Updates deployment documentation and static discovery for agents; the MCP server and the guidance it retrieves remain in Brazilian Portuguese.
